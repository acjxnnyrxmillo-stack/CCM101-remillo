# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This lab covers deploying an S3-compatible storage server (MinIO) using Docker, accessing it through a web console via port forwarding, and creating a storage bucket to hold uploaded files simulating proof-of-concept storage backend for a photo-sharing application.

## Objectives

-Differentiate between Block, File, and Object storage.

-Deploy an S3-compatible Object storage server (MinIO) using Docker.

-Access a cloud service via a web interface using port forwarding.

-Create a storage bucket and upload objects to the cloud.

-Document cloud storage operations using Markdown.

## Tools Used

-KillerCoda Playground (Ubuntu)

-Docker

-MinIO (S3-compatible object storage)

-Github

## Skills Learned

-Deploying a containerized service with environment variables in Docker.

-Accessing a service running inside a container through port forwarding.

-Creating and managing storage buckets in an S3-compatible system.

-Documenting technical deployments in Markdown.

-Troubleshooting a real-world issue (a discontinued Docker image) by finding and using an alternative source.
