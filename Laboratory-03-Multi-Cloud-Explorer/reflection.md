Mission Reflection


1. Which cloud platform impressed you the most?

-The cloud platform that impressed me the most was Google Cloud Platform (GCP), mainly because of the number of tools and resources it offers, especially for AI and machine learning. I found its tools more useful and relevant to what I want to explore in the future.

2. What similarities exist among AWS, Azure, and GCP?

-One similarity I noticed among AWS, Azure, and GCP is that they all offer the same basic types of services, just with different names — like virtual machines, storage, and databases. They also all have their own web-based dashboard for managing everything, and they use a pay-as-you-go pricing system.

3. How do business requirements influence cloud platform selection?

-Business requirements greatly influence which cloud platform a company should choose because each platform has its own strengths that are suitable for different needs. For example, a company already using Microsoft tools would benefit more from Azure, while a company focused on AI and machine learning would be better off with GCP. This shows that there is no single "best" cloud platform — the right choice depends on what the business actually needs.

4. What did you learn from acting as a Cloud Solutions Consultant?

-Acting as a Cloud Solutions Consultant taught me that choosing a cloud platform is not just about picking the most popular one, but about carefully thinking through which platform fits the situation best. I also learned the importance of choosing tools that are easier for me to understand, since that affects how well I can use and explain them to others.

 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?
    
-This mission also helped improve my GitHub Cloud Computing Portfolio by teaching me the importance of keeping files well-organized. By creating clear folders and properly named Markdown files for each part of the exam, it becomes easier to find specific information later on instead of forgetting where things are saved. This experience showed me that a well-structured portfolio is not just for submission purposes, but also useful for my own future reference.

Overall, this mission helped me think more like a real cloud consultant — someone who analyzes needs first before recommending a solution, and who values clear documentation as much as technical knowledge.
