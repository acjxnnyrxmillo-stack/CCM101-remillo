Client Recommendations

Client A - Startup Company

Recommended Platform: Amazon Web Services (AWS)

AWS is the best fit for this startup because of its flexible pay-as-you-go pricing model, which helps keep costs low while the company is still small. AWS also offers a wide range of services that can support the app as it grows, so the startup won't need to switch providers later. Its scalability allows the company to easily increase resources as user demand grows the next few years.

Services they could use:

Amazon EC2

Amazon S3

AWS Lambda

Client B - University

Recommended Platform: Microsoft Azure 

  Azure is the deal choice for the university since it already relies heavily on Microsoft products such as Windows Server, Microsoft 365, and Active Directory. Azure offers seamless integration with these existing tools, which reduces the complexity of migration. This allows the university to extend its current identity management system to the cloud without needing to rebuild it from scratch.

  Services they could use:

  Azure Active Directory 

  Azure Virtual Machines

  Azure Blob Storage

  Client C - AI Research Company
  
  Recommended Platform: Google Cloud Platform

  GCP is the strongest choice for this AI research company due to its industry-leading tools for artificial intelligence and  machine learning. GCP offer vertex AI, which makes it easier to build, train and deploy machine learning models. It also has  native and optimized support  for TensorFlow, a popular framework used in AI research.

  Services they could use:

  Vertex AI

  Compute Engine

  Cloud Storage

  Client D - Global E-Commerce Company
  
  Recommended Platform: Amazon Web Services

  AWS is the most suitable platform for this global e-commerce company because of its extensive global infrastructure, with data centers and availability zones spread across many regions worldwide. This ensures low latency and high availability for customer regardless of location. AWS also offers auto-scaling features that automatically adjust computing resources based on traffic, which is essential for handling demand spikes such as sales events. Its proven track record with large-scale e-commerce platform ( including Amazon itself) makes it a reliable choice for this type of business.

  Services they could uses:

  Amazon EC2 with auto scaling

  Amazon CloudFront

  Amazon RDS
  


Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|------------------------|------------------------|----------------|
| Startup Company | AWS | Offers flexible pay-as-you-go pricing and a wide range of scalable services, ideal for a growing business with a limited budget. |
| Enterprise Organization | AWS | Provides the broadest service catalog and largest global infrastructure, suitable for complex, large-scale enterprise needs. |
| Microsoft Environment | Azure | Seamlessly integrates with existing Microsoft tools such as Windows Server, Active Directory, and Microsoft 365. |
| AI / Machine Learning | GCP | Offers industry-leading AI/ML tools like Vertex AI and strong native support for TensorFlow. |
| Kubernetes Deployment | GCP | Google created Kubernetes, giving GCP the most mature and reliable container orchestration support through GKE. |
| Global Web Application | AWS | Has the largest number of regions and availability zones worldwide, ensuring low latency and high availability for global users. |
